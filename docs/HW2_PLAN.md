# ДЗ2: план до просмотра результатов

Источник требований: [HomeWork_2.md](https://github.com/PikaChuChuMF/RnD-ML-Course-2026-2/blob/main/HW_2/HomeWork_2.md).

Опорная модель — лучшая конфигурация ДЗ1: TF-IDF + позиционные признаки +
SGDClassifier с logistic loss и balanced class weights. Её macro span F1
на трёх фолдах — 0,3883 ± 0,0016. Фиксируются два изменения, без HPO.

## H1. Контекст соседних кандидатов

В ДЗ1 Rebuttal имеет F1=0,1251, Claim=0,2515. Изолированная фраза плохо
отражает, отвечает ли автор на возражение или вводит новый тезис. Добавление
TF-IDF предыдущего и следующего кандидата отдельными блоками с фиксированным
весом 0,35 должно увеличить macro span F1 относительно baseline; дополнительно
сравнивается средний recall Counterclaim/Rebuttal.

Словарь и IDF обучаются только на текущих train-кандидатах; соседние тексты
преобразуются тем же vectorizer. Контекст строится только внутри одного эссе,
не использует меток или предсказаний соседей. На inference доступен весь текст,
поэтому следующий кандидат допустим. Переход через абзац разрешён, через
границу эссе — запрещён.

## H2. Избирательное объединение фрагментов

В ДЗ1 Claim в среднем занимает 17,4 слова, Evidence — 77,4. Объединение всех
соседних кандидатов одинакового класса может склеить несколько коротких тезисов
и ухудшить overlap. Новый decoder объединяет только Lead, Evidence и
Concluding Statement внутри абзаца. Для Claim, Position, Counterclaim и
Rebuttal сохраняются границы кандидатов. Ожидаются рост recall Claim и общего
macro span F1, но возможны лишние FP из-за разделения одного длинного аргумента.
Список классов зафиксирован до эксперимента, по validation не подбирается.

## Эксперимент и абляции

Полный факторный план: baseline; только контекст; только decoder; оба изменения.
Две обязательные абляции относительно `context_decoder`:

1. Убрать контекст → `decoder_only`.
2. Убрать избирательное объединение → `context_only`.

Все четыре варианта оцениваются на тех же трёх essay/group-фолдах ДЗ1,
seed=42, той же span-метрикой. Разбиение пересоздаётся детерминированно и
сверяется с сохранённым разбиением ДЗ1, если оно присутствует. Исходные
кандидаты, обучающие метки, TF-IDF-параметры, структура, регуляризация,
class weights и правила matching фиксированы. Меняются только указанные
блоки контекста и decoder. Пары с одинаковым классификатором используют
одни и те же предсказания: добавление decoder не требует повторного обучения.

Поддержка гипотезы о качестве: положительный Δ pooled OOF macro F1 и
положительная нижняя граница парного 95% cluster-bootstrap CI (1000 повторов,
группа нормализованных эссе). Изменения recall описательны. Если CI содержит
ноль, эффект считаем неразличимым на этом split; отрицательный CI означает
ухудшение. Дополнительно оценивается взаимодействие двух компонентов.

Выбор модели — максимум среднего macro span F1 по трём validation-фолдам.
Положительный результат не гарантируется; отрицательные результаты сохраняются.
После просмотра чисел параметры не меняются. Test и leaderboard в настройке
и выборе не участвуют. Bootstrap условен относительно фиксированных OOF-
предсказаний, не учитывает подбор конфигурации и вариативность переобучения.
ДЗ1 уже изучало эти фолды, поэтому независимая итоговая оценка потребует
нового закрытого test или внешнего цикла CV.
